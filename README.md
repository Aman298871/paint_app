# 🎨 Paint App

A simple and interactive Paint Drawing App developed using **Kotlin** and **Jetpack Compose**. The application allows users to draw freely on a canvas, select different brush colors, adjust brush size, erase drawings, clear the canvas, and save their artwork to the device gallery.

## ✨ Features

* Draw on a canvas using touch gestures
* Multiple color options
* Adjustable brush size
* Eraser functionality
* Reset/Clear canvas
* Save drawing to gallery
* Modern UI built with Jetpack Compose
* Lightweight and beginner-friendly project

## 🛠️ Tech Stack

* Kotlin
* Jetpack Compose
* Material 3
* Android Canvas API
* MediaStore API

## 🚀 Getting Started

### Prerequisites

* Android Studio
* Android SDK 26+
* Kotlin

### Installation

1. Clone the repository

```bash
git clone https://github.com/aman298871/paint_app.git
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Run the application on an emulator or physical device
